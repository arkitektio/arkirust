# rekuest-protocol

The frames of the rekuest agent protocol (`/agi`), for both sides: agents (the
[`rekuest`](../rekuest) crate) and servers.

The contract is `tests/fixtures/agent_wire_examples.json`, generated by the rekuest server
(`scripts/dump_wire_examples.py`) with every field of every message set. Each frame in it
must parse into these types and serialize back to the same JSON.
